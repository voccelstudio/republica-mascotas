1. Introducción

República Mascotas es un sistema de gestión veterinaria integral, diseñado para funcionar completamente offline (sin necesidad de internet). Se ejecuta con solo abrir un archivo index.html en cualquier navegador moderno (Chrome, Edge, Firefox).

Los datos se almacenan en el disco de la PC mediante IndexedDB (base de datos local del navegador) y pueden respaldarse manual o automáticamente en formato JSON.

✔ 100% offline

No requiere servidor, internet ni conexión externa. Abrí el archivo y funcioná.

✔ Multiplataforma

Anda en Windows, Mac, Linux, tabletas. Solo necesitás un navegador.

✔ Sin instalación

Doble clic en index.html y ya está listo para usar. No requiere permisos de administrador.

✔ Respaldo automático

Copia de seguridad semanal automática con descarga del archivo JSON.

2. Requisitos técnicos

  • Sistema operativo: Windows 10/11, macOS, Linux o tablet con navegador moderno.
  • Navegador: Google Chrome (recomendado), Microsoft Edge, Mozilla Firefox o Safari. Debe estar actualizado.
  • Almacenamiento: Espacio libre en disco para la carpeta donde se guarda el sistema y los respaldos.
  • Internet: No es necesario para el funcionamiento diario. Solo se requiere para la función de WhatsApp Web (si se usa).

3. Instalación y puesta en marcha

  1. Descargar la carpeta completa del sistema.
  2. Abrir el archivo index.html con doble clic. Se abrirá en el navegador predeterminado.
  3. En la primera ejecución, el sistema crea automáticamente la base de datos local.
  4. Ir a Configuración para personalizar: nombre de la clínica, logo, teléfono, datos fiscales, etc.
  5. Si se desea probar con datos de ejemplo, ir a Configuración → Respaldo & Restaurar → Cargar datos de ejemplo.

💡 Tip: Se puede crear un acceso directo en el escritorio a index.html para abrirlo más rápido.

5. Gestión de Pacientes

Registro de un paciente

  1. Ir a Pacientes → + Nuevo Paciente.
  2. Completar: nombre, apellido (se autocompleta con el del dueño), especie, raza (con opción "Otra raza" para escribir una personalizada), sexo, castrado, edad, peso, color, microchip, señas particulares.
  3. Datos del dueño: nombre, teléfono, email y dirección. Si se escribe el nombre de un dueño ya registrado, el apellido se autocompleta.
  4. Se puede agregar una foto del paciente (máximo 2 MB).
  5. Completar alertas (alergias, cuidados especiales) y notas internas.

Historial clínico

Cada paciente tiene un perfil con pestañas de:

  • Información general — datos básicos, foto, alertas, notas
  • Servicios — historial de servicios prestados
  • Procedimientos — procedimientos realizados y próximos
  • Vacunas — registro de vacunas aplicadas con próximas fechas
  • Recetas — prescripciones y medicación recetada
  • Reporte PDF — genera un informe completo imprimible del paciente

WhatsApp

Desde el perfil del paciente se puede enviar un mensaje de WhatsApp al dueño con un solo clic. Hay mensajes predefinidos para:

  • Recordatorio de turno
  • Recordatorio de próxima vacuna
  • Recordatorio de próximo procedimiento
  • Mensaje personalizado

6. Gestión de Clientes

El módulo de Clientes agrupa automáticamente a los dueños por nombre y teléfono. Muestra:

  • Nombre del dueño, teléfono, email y dirección
  • Cantidad de mascotas registradas
  • Badges con los nombres de cada mascota (clic para ir al perfil)
  • Tabla completa de todas las mascotas del dueño

7. Agenda / Turnos

  • Vista de turnos del día, con filtro para ver cualquier fecha.
  • Cada turno se puede marcar como Pendiente, Atendido o Cancelado.
  • Registrar Turno: seleccionar paciente, fecha, hora y motivo. Opcionalmente se pueden agregar notas internas.
  • Los turnos aparecen destacados con colores según su estado.

8. Servicios

  • Registro de cada servicio prestado: tipo (Consulta, Vacunación, Baño, etc.), profesional, fecha, hora y notas.
  • Se pueden registrar insumos utilizados en las notas con el formato [Insumo utilizado: Nombre x1]. Estos aparecen automáticamente en los reportes PDF.
  • Búsqueda por nombre de paciente o apellido.
  • Filtros por tipo de servicio.

9. Procedimientos

  • Registro de procedimientos con categorías personalizables (por defecto: Baño, Control, Vacunas, Pipetas).
  • Cada procedimiento puede tener una próxima fecha programada (ej: "Próximo baño medicado: 15/07/2026").
  • Las categorías y los nombres de procedimientos se administran desde Configuración.

10. Inventario y Código de Barras

Control de Stock

  • Registro de productos con nombre, stock actual, stock mínimo de alerta y precio.
  • Indicadores visuales: Normal, Bajo (stock ≤ mínimo), Sin Stock.
  • Resumen en la parte superior: total de productos, bajo stock, sin stock.

Escaneo con Código de Barras

El sistema soporta lectores de código de barras (scanner USB). Estos funcionan como un teclado: al escanear, escriben el número y envían un Enter automáticamente.

Flujo de escaneo:

  1. En la pantalla de Inventario hay un campo de texto "Escaneá un código de barras...".
  2. Se apunta el lector al código y se escanea. El número se escribe solo.
  3. El sistema busca el producto en la base de datos local.
  4. Si el producto existe → se abre una ventana para agregar stock rápidamente.
  5. Si el producto no existe → se abre el formulario de nuevo producto con el código ya precargado.
  6. En el formulario de producto también se puede ingresar o modificar el código de barras manualmente.

11. Reportes PDF

Desde el perfil de cada paciente se puede generar un Reporte PDF completo que incluye:

  • Encabezado con logo de la clínica, nombre, dirección, teléfono, email, RUT, veterinario y fecha.
  • Foto y datos del paciente: especie, raza, sexo, edad, peso, color, microchip.
  • Datos del dueño: nombre, teléfono, email.
  • Alertas del paciente.
  • Notas internas.
  • Servicios realizados (tabla con fecha, tipo, profesional, insumos utilizados, observaciones).
  • Procedimientos realizados (tabla con fecha, categoría, profesional, insumos, observaciones).
  • Medicamentos recetados si existen recetas activas.
  • Pie de página con la fecha de emisión y datos de la clínica.

El PDF se genera en el navegador y se puede guardar o imprimir. Si hay algún problema con la generación, automáticamente abre la ventana de impresión del navegador como respaldo.

Datos que aparecen en el PDF:

12. Configuración

Datos de la clínica

  • Nombre, dirección, teléfono, email, RUT
  • Veterinario a cargo (aparece en PDFs)
  • Logo de la clínica (imagen subida localmente)
  • Preferencias del PDF (mostrar logo, mostrar RUT)

Personalización visual

  • Tema de color: 6 combinaciones predefinidas (Clásico, Bosque, Lavanda, Atardecer, Marino, Roble)
  • Modo oscuro: activable desde Configuración o con el botón de la barra lateral

Tipos de servicio

Por defecto: Consulta General, Consulta Especializada, Vacunación, Baño Medicado, Cirugía, Análisis Clínicos, Ecografía, Radiografía, Peluquería, Emergencia, Control. Se pueden agregar o quitar libremente.

Categorías de procedimientos

Se administran las categorías (Baño, Control, Vacunas, Pipetas) y los procedimientos dentro de cada una. Se pueden agregar, renombrar o eliminar.

Especies y razas

Por defecto: Perro (28 razas), Gato (10 razas), Conejo (4 razas), Ave (3 razas), Hamster, Tortuga, Hurón, Caballo, Vaca, Cabra, Cerdo, Otros. En cualquier especie se puede seleccionar "Otra raza..." para escribir una personalizada.

13. Respaldo y Restauración

Respaldo manual

Ir a Configuración → Respaldo & Restaurar → Exportar respaldo. Se descarga un archivo republica_mascotas_backup_YYYY-MM-DD.json con todos los datos.

Respaldo automático

El sistema verifica automáticamente si pasaron 7 días desde el último respaldo. Si es así, muestra un banner con una cuenta regresiva de 5 segundos y descarga el respaldo automáticamente. El usuario puede hacer clic en "Ahora" para descargarlo inmediatamente y cancelar la cuenta regresiva.

Restauración

Ir a Configuración → Respaldo & Restaurar → Restaurar desde JSON. Seleccionar un archivo .json de respaldo. Esto reemplaza todos los datos actuales.

Datos de ejemplo

El botón "Cargar datos de ejemplo" en Configuración → Respaldo & Restaurar carga un conjunto de datos de prueba (5 pacientes, 10 productos, 7 servicios, 8 procedimientos, 3 turnos) para evaluar el sistema.

14. Soporte técnico

  • Actualizaciones: reemplazar la carpeta del sistema por la nueva versión conservando los respaldos.
  • Migración a otra PC: generar un respaldo JSON en la PC original, copiar la carpeta del sistema a la nueva PC, abrir index.html y restaurar desde el JSON.
  • Problemas comunes:
    • Si la base de datos se corrompe, restaurar desde el último respaldo JSON.
    • Si el navegador bloquea la apertura del archivo, hacer clic derecho sobre index.html → "Abrir con" → Chrome/Edge.
    • Los datos de la base de datos local son específicos del navegador. Si se abre el sistema en otro navegador, los datos no estarán visibles hasta restaurar un respaldo.
